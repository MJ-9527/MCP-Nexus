## 第 1 周：基础架构

### 目标
搭建网关代理骨架、注册中心、数据库初始化，实现工具列表与健康检查。

| 1.2 | PostgreSQL 迁移脚本 | ✅ 完成 | `db/migrations/001~003`、`seed.sql` |
| 1.3 | 网关代理骨架（Gin + pgxpool） | ✅ 完成 | `cmd/server/main.go`、`config/` |
| 1.4 | MCP Server 注册中心 | ✅ 完成 | `repository/postgres_server.go`、`service/server_service.go` |

| 1.6 | 定时健康检查（60s 间隔） | ✅ 完成 | `service/server_service.go` StartPeriodicHealthCheck |

| 1.8 | 示例 MCP Server（db-server） | ✅ 完成 | `examples/db-server/` |

### 关键设计决策
- 传输协议：仅支持 Streamable HTTP
- Repository 接口双实现：PostgreSQL + Memory（用于单元测试）
- 健康检查结果包含 status（online/offline/degraded）、latency、timestamp

### 验收标准

- [ ] 合法用户可登录并调用已授权工具
- [ ] 无权限 Agent 调用敏感工具 100% 被拒，生成审计记录
- [ ] JWT 缺失/伪造/过期时请求被拒绝
- [ ] 限流超阈值返回 429
- [ ] 未发布或不健康工具不可调用
- [ ] OpenAPI 示例可生成可运行 MCP Server 骨架
- [ ] Agent 完成"查询数据库→生成报表"完整任务
- [ ] 网关 P99 < 5ms
- [ ] 测试环境吞吐 ≥ 2000 QPS
- [ ] Docker Compose 一键启动后健康检查通过
