# MCP-Nexus 使用手册

本文档面向使用者，按步骤操作即可完成从启动到演示的完整流程。

- 推荐环境：Windows 10/11 + Docker Desktop
- 系统要求：Docker 20.10+、Docker Compose 2.0+、4GB 可用内存
- 前端页面：http://localhost:5173
- 后端网关：http://localhost:8080

---

## 一、快速开始（推荐：Docker 一键启动）

> 以下命令在 PowerShell 中执行。唯一推荐路径，全程不需要本地安装 Go / Node / PostgreSQL。

### 步骤 1：确认 Docker 已运行

```powershell
docker --version
docker compose version
```

若未安装，请先安装 Docker Desktop 并启动。

### 步骤 2：启动全部服务

```powershell
cd MCP-Nexus\deploy
docker compose up -d
```

首次启动会构建镜像并初始化数据库，约需 2~5 分钟。

### 步骤 3：确认服务健康

```powershell
docker compose ps
```

确认 8 个容器状态均为 `running` / `healthy`：

| 服务 | 容器名 | 端口 | 作用 |
|---|---|---|---|
| gateway | mcp-nexus-gateway | 8080 | 网关 API |
| postgres | mcp-nexus-postgres | 5432 | 业务数据库 |
| redis | mcp-nexus-redis | 6379 | 限流 |
| clickhouse | mcp-nexus-clickhouse | 8123/9000 | 审计日志 |
| demo-service | mcp-nexus-demo | 9001 | Echo 示例工具 |
| file-server | mcp-nexus-file | 9002 | 文件操作工具 |
| http-server | mcp-nexus-http | 9003 | HTTP 代理工具 |
| db-server | mcp-nexus-db | 9004 | 销售数据库工具 |

健康探针：

```powershell
curl http://localhost:8080/health
```

### 步骤 4：启动前端页面（可选）

后端 API 已可直接使用；如需图形界面：

```powershell
cd d:\Learn\MCP-Nexus\MCP-Nexus\web
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。

> 首次使用需要本机已安装 Node.js 18+。前端开发服务器会自动把 `/api` 请求代理到 `http://localhost:8080`。

### 步骤 5：停止服务

```powershell
cd d:\Learn\MCP-Nexus\MCP-Nexus\deploy
docker compose stop        # 停止，保留数据
docker compose down        # 删除容器，保留数据卷
docker compose down -v     # 删除容器并清空所有数据（慎用）
```

## 二、账号与角色

系统内置 3 个账号，密码已写入初始化数据：

| 用户名 | 密码 | 角色 | 可做什么 |
|---|---|---|---|
| `admin` | `admin123` | 平台管理员 | 发布/下线工具、配置权限、导入 OpenAPI/Skills、查看审计与统计 |
| `developer` | `dev123` | 工具开发者 | 注册 Server/工具、查看统计 |
| `agent` | `agent123` | Agent 调用者 | 浏览市场、调用已授权工具、评分评论 |

> 生产环境请通过 `.env` 的 `JWT_SECRET` 更换密钥，并修改默认密码。

各角色限流（每分钟最大请求数）：

| 角色 | 限流 |
|---|---|
| admin | 600 次/分钟 |
| developer | 300 次/分钟 |
| agent | 120 次/分钟 |

超出限流返回 HTTP `429`。

## 三、三种典型使用方式

### 方式 A：网页操作（最简单）

1. 打开 http://localhost:5173
2. 用 `admin` / `admin123` 登录
3. 顶部导航三个页面：
   - **市场**：浏览、搜索工具，查看详情，生成接入配置，评分评论
   - **统计**：总调用量、趋势、Top 工具、成功率、异常告警
   - **审计**：按工具/角色/状态筛选调用日志

### 方式 B：命令行调用 API

所有受保护接口都需要在请求头携带 `Authorization: Bearer <token>`。

#### 1. 登录获取 Token

```powershell
$resp = Invoke-RestMethod -Uri "http://localhost:8080/api/auth/login" `
  -Method Post -ContentType "application/json" `
  -Body '{"username":"admin","password":"admin123"}'
$token = $resp.data.token
$headers = @{ Authorization = "Bearer $token" }
```

> Linux/macOS 可用 `curl -X POST .../api/auth/login -H 'Content-Type: application/json' -d '{...}'`。

#### 2. 浏览工具市场

```powershell
Invoke-RestMethod "http://localhost:8080/api/market/tools?page=1&page_size=10" -Headers $headers
```

常用查询参数：

| 参数 | 说明 | 示例 |
|---|---|---|
| `keyword` | 关键词（匹配名称/描述） | `keyword=sales` |
| `category` | 分类 | `category=数据库` |
| `page` / `page_size` | 分页 | `page=1&page_size=10` |

#### 3. 查看工具详情与接入配置

```powershell
Invoke-RestMethod "http://localhost:8080/api/market/tools/1" -Headers $headers
Invoke-RestMethod "http://localhost:8080/api/market/tools/1/config-snippet" -Headers $headers
```

#### 4. 调用工具（经网关）

Agent 账号登录后调用已授权工具：

```powershell
$agent = Invoke-RestMethod "http://localhost:8080/api/auth/login" -Method Post `
  -ContentType "application/json" -Body '{"username":"agent","password":"agent123"}'
$ah = @{ Authorization = "Bearer $($agent.data.token)" }

Invoke-RestMethod "http://localhost:8080/mcp/tools/query_sales/call" -Method Post `
  -Headers $ah -ContentType "application/json" `
  -Body '{"arguments":{"month":"2026-01"}}'
```

#### 5. 查看统计与审计

```powershell
Invoke-RestMethod "http://localhost:8080/api/analytics/overview" -Headers $headers
Invoke-RestMethod "http://localhost:8080/api/audit/logs?page=1&page_size=20" -Headers $headers
```

审计日志筛选参数：

| 参数 | 说明 |
|---|---|
| `tool_name` | 按工具名 |
| `role` | 按角色（admin/developer/agent） |
| `success` | `true` 成功 / `false` 失败 |
| `since_hours` | 最近 N 小时 |
| `page` / `page_size` | 分页 |

### 方式 C：一键演示脚本

#### Agent 查库生成报表（核心演示场景）

```powershell
cd d:\Learn\MCP-Nexus\MCP-Nexus
```

## 四、管理员操作指南

以下操作均需 **admin** 角色。

### 1. 注册新 MCP Server

`POST /api/servers`

```json
{
  "name": "my-server",
  "description": "业务工具服务",
  "endpoint": "http://host:9005",
  "version": "1.0.0"
}
```

### 2. 注册工具

`POST /api/tools`

```json
{
  "server_id": 1,
  "name": "query_orders",
  "description": "查询订单",
  "category": "数据库",
  "tags": ["order"],
  "input_schema": {"type": "object", "properties": {}},
  "version": "1.0.0"
}
```

新注册工具默认未发布，市场和网关均不可见。

### 3. 发布 / 下线工具

```powershell
Invoke-RestMethod "http://localhost:8080/api/tools/1/publish"  -Method Post -Headers $headers -Body '{}' -ContentType "application/json"
Invoke-RestMethod "http://localhost:8080/api/tools/1/offline"  -Method Post -Headers $headers -Body '{}' -ContentType "application/json"
```

### 4. 配置角色权限

`POST /api/tools/:id/permissions`

```powershell
# 授权 agent 调用 query_sales
Invoke-RestMethod "http://localhost:8080/api/tools/1/permissions" -Method Post `
  -Headers $headers -ContentType "application/json" `
  -Body '{"role":"agent","tool_name":"query_sales","action":"grant"}'

# 撤销授权
Invoke-RestMethod "http://localhost:8080/api/tools/1/permissions" -Method Post `
  -Headers $headers -ContentType "application/json" `
  -Body '{"role":"agent","tool_name":"query_sales","action":"revoke"}'
```

- `action`：`grant`（授权）或 `revoke`（撤销）
- `tool_name` 填 `*` 表示该角色放行全部工具

### 5. 导入 OpenAPI 自动生成 MCP 工具

`POST /api/openapi/import`，请求体提交 OpenAPI 3.x 的 JSON/YAML 文本。系统会解析 GET/POST 接口，自动生成 MCP 工具定义和 Go Server 骨架。重复导入同名/同地址服务会幂等复用，不会产生重复数据。

### 6. 导入 Skills

`POST /api/skills/import`，提交标准化 Skills 定义，系统将其转换为虚拟 MCP Server 下的工具。

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/auth/login` | 公开 | 登录获取 JWT |
| GET | `/health` | 公开 | 健康探针 |
| GET | `/api/market/tools` | 登录 | 工具市场列表 |
| GET | `/api/market/tools/:id` | 登录 | 工具详情（仅已发布） |
| GET | `/api/market/tools/:id/config-snippet` | 登录 | 接入配置片段 |
| GET/POST | `/api/market/tools/:id/reviews` | 登录 | 评论列表 / 提交评分 |
| GET | `/api/market/ranking` | 登录 | 调用量排行 |
| GET | `/mcp/tools` | 登录+限流 | 当前角色可用工具 |
| POST | `/mcp/tools/:name/call` | 登录+限流+授权 | 调用工具 |
| GET | `/api/analytics/overview` | admin/developer | 统计概览 |
| GET | `/api/audit/logs` | admin/developer | 审计日志 |
| POST | `/api/servers` | 开发者 | 注册 Server |
| POST | `/api/tools` | 开发者 | 注册工具 |
| POST | `/api/tools/:id/publish` | admin | 发布工具 |
| POST | `/api/tools/:id/offline` | admin | 下线工具 |
| POST | `/api/tools/:id/permissions` | admin | 配置权限 |
| POST | `/api/openapi/import` | admin | OpenAPI 导入 |
| POST | `/api/skills/import` | admin | Skills 导入 |

所有响应统一格式：

```json
{
  "code": "OK",
  "message": "ok",
  "request_id": "唯一请求ID",
  "data": { }
}
```

错误时 `code` 为业务错误码（如 `TOOL_NOT_FOUND`、`FORBIDDEN`、`INVALID_TOKEN`）。

## 七、架构概览

```
Agent ──JWT──> Gateway (Gin :8080)
                  ├── Auth Middleware (JWT 校验)
                  ├── RBAC Middleware (角色检查)
                  ├── Rate Limit Middleware (Redis 令牌桶)
                  ├── Proxy Service (工具发现/调用)
                  │     ├── PostgreSQL (工具/权限元数据)
                  │     └── MCP Server (HTTP 转发)
                  ├── Audit Service (ClickHouse 异步写入)
                  └── Market Service (浏览/搜索/评分/排行)
```

- **北向（Agent → 网关）**：同时支持 REST（`/mcp/tools`、`/mcp/tools/:name/call`）与标准 MCP JSON-RPC（`POST /mcp`，`initialize`/`tools/list`/`tools/call`）。
- **南向（网关 → 工具 Server）**：转发到各示例/业务 Server 的 `/tools/:name/call`。
- 工具元数据、权限存 PostgreSQL；限流计数存 Redis；调用审计异步批量写 ClickHouse。

## 八、常见问题（FAQ）

**Q：启动后访问 8080 无响应？**
等待约 30 秒让 gateway 完成数据库初始化；用 `docker compose logs gateway` 查看日志。

**Q：忘记初始化数据库？**
PostgreSQL 首次启动会自动执行 `db/migrations/` 下脚本。若使用了旧数据卷导致脚本未执行，可手动导入：

```powershell
Get-Content ..\db\migrations\001_create_mcp_servers.sql | docker exec -i mcp-nexus-postgres psql -U mcp -d mcp_platform -f -
```

**Q：登录提示密码错误？**
确认初始化数据已加载（全新数据卷）。默认账号见第二节。

**Q：调用工具返回 403 FORBIDDEN？**
当前角色未被授权调用该工具。请用 admin 通过 `/api/tools/:id/permissions` 授权。

**Q：调用工具返回 429？**
触发了角色限流，等待下一分钟窗口重置。

**Q：调用工具返回 TOOL_OFFLINE？**
工具未发布或对应 Server 健康检查为 offline。请在管理后台发布并确认 Server 在线。

**Q：统计页面无数据？**
审计数据写入 ClickHouse，需先有成功/失败的工具调用记录。先执行一次工具调用或演示脚本。

**Q：如何彻底重置环境？**

```powershell
docker compose down -v
docker compose up -d
```
