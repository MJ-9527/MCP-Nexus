# MCP-Nexus 项目文件说明

## 目录结构总览

```
MCP-Nexus/
├── cmd/            程序入口
├── config/         配置加载
├── db/             数据库迁移脚本
├── deploy/         Docker 部署
├── docs/           文档
├── does/           需求文档与开发计划
├── examples/        示例 MCP Server
├── handler/        HTTP 请求处理层（Gin Handler）
├── middleware/      Gin 中间件
├── model/          数据模型定义
├── permission/     权限客户端接口
├── repository/     数据访问层（PostgreSQL + Memory 双实现）
├── router/         路由注册
├── scripts/        运维脚本
├── service/        业务逻辑层
├── web/            前端应用（React 19 + TS + Vite）
├── .env            环境变量配置
├── .env.example    环境变量模板
├── go.mod          Go 模块依赖声明
└── go.sum          Go 依赖校验文件
```
